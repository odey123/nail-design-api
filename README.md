# Nail Design API

A backend mock API to manage custom nail designs. Built with Node.js, Express, and MongoDB. Supports user registration, login, saving custom designs, and retrieving them securely.

---

## 🛠 Features

- ✅ User Registration & Login (JWT Authentication)
- ✅ Save Custom Nail Designs (shape, color, length)
- ✅ Retrieve Logged-in User's Designs
- ✅ Protected Routes with Middleware
- ✅ MongoDB + Mongoose

---

## 📦 Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- JSON Web Tokens (JWT)
- bcryptjs
